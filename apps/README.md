# App builds (not committed)

Download the latest **My Demo App (React Native)** builds from
https://github.com/saucelabs/my-demo-app-rn/releases and place them here:

| Platform | Release asset | Save as |
| --- | --- | --- |
| Android | the `.apk` file (name starts with `Android`) | `apps/MyDemoAppRN.apk` |
| iOS simulator | the `iOS-Simulator-...zip` file, then unzip it | `apps/MyDemoAppRN.app` |

Or point the framework elsewhere with `-Dandroid.app=/path/to/app.apk` or `-Dios.app=/path/to/App.app`.
